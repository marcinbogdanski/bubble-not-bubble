# Is AI a bubble? A live, evidence-backed assessment

*Status: research in progress. This page will hold the answer once the first
research pass (theory, full stack, macro) is complete. Started 2026-10-17.*

## What this is

A first-principles, data-backed assessment of whether the current AI
investment boom is a financial bubble, where in the stack the risk sits, and
what would tell us the picture has changed. The answer is not binary. It is a
set of explicit, resolvable probability forecasts at 6, 12 and 24 months,
differentiated by layer of the stack, each tied to evidence.

## How it is built

- **[Methodology](/report/methodology)**: definitions, confidence grades,
  forecast rules, how agents are used.
- **Research notes** (sidebar): one note per company, layer or topic, each
  with a claim table and sources. The report cites them.
- **Forecasts**: the register of questions, probabilities and update history.
- **Signals**: dated log of new information and what it changed.

Everything is in the [repository](https://github.com/marcinbogdanski/bubble-not-bubble),
including the agent chats that built it. Agents can start from [llms.txt](/llms.txt).
